## Scope since v0.0.189 (62 non-merge commits)

- Streaming request inspection in the HTTPS proxy: header-time body policy, pass-through
  streaming of uninspected bodies, incremental JSON lexer and metadata sniffer, streaming
  content decoders, and unit-wise streamed secret detection and masking for requests above
  16 MiB (Off/Notify/Redact, GuardRails skipped). Fix: buffered `deflate` request bodies that
  decode to more than 8 KiB are no longer rejected.
- LocalRouter management MCP server, its Try It Out testing and Monitor payload capture.
- Push Relay: stateless reach of 2026-07-28 upstreams, non-ASCII `Mcp-Name` encoding,
  resource-update ingress and the Claude Channels permission relay.
- `/v1/responses` firewall approvals and MCP-via-LLM parity with chat.
- Atomic rate-limit admission for in-flight requests (requests now reserve `max_tokens`;
  paid-fallback retries are admitted like other requests and can return 429); failover tests.
- Skill installs: extraction budgets and atomic installs (marketplace skills with an
  unparsable `SKILL.md` are rejected; existing archive extractions are re-extracted once).
- Truthful endpoint capability matrix; RFC 6749 form-encoded OAuth token requests.
- HTTPS-proxy client config sync and listener lifecycle; `settings.yaml` watcher re-enabled.
- Website demo mocks every frontend-invoked command; approval popup model list fix.
- Dead-code removal (about 7,400 lines, 74 uninvoked Tauri commands).
- CI: parallel lint, retried release builds, 120-minute platform builds, cache pruning.
