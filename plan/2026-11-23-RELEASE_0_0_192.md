## Scope since v0.0.191

- The server listens only on its configured port; a taken port leaves the server stopped with
  the reason shown in the sidebar, tray and server settings. Changing the host or port restarts
  the server. Network settings move to Settings → General. See
  `plan/2026-11-23-STRICT_SERVER_PORT.md`.

Behaviour change users may notice: an install whose port was taken (and that silently ran on
the next port) now shows the server as stopped until the port is freed or changed.
