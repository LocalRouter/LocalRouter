# LocalRouter 0.0.171 release

The owner explicitly requested a new LocalRouter release containing the Responses
translator fix. This supersedes the earlier restriction on merging, pushing and
publishing this fix. It does not require changing the installed running app.

Candidate: ff7a3474079a61d047521838c86e4a803f0de203, based on master
92eaf570. It preserves final tool arguments from standard Responses completion
events, keeps parallel call identities stable, and emits only missing argument
suffixes. No Jazyk-specific wire adapter is added.

The candidate passed stable Rust 1.99.1 workspace tests (4,690 passed, 69 ignored,
zero failed), workspace all-target Clippy with warnings denied, formatting and
15 final translator tests. The captured real Responses stream passes the patched
translator and unmodified public GDK Chat streaming codec with two exact tool
arguments. The original completed payload also passes the public Responses codec.

At preflight, v0.0.170 is the latest stable release and v0.0.171 is unused. The
standard release.yml owns manifest/lockfile version bumps, tag creation, native
binaries, signed updater assets, generated release notes and normal follow-ups.
Package-manager publishing and Snap Store uploads are intentionally disabled in
the existing workflow. They are not promised by this release.

Preserve the unrelated untracked old release plans in the main checkout. Do not
restart or replace the installed LocalRouter app during publication.
