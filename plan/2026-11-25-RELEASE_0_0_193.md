## Scope since v0.0.192

- `SSL_CERT_FILE`-style proxy CA variables (Codex's permanent `.env`, Aider, generic tools) point
  at a bundle of the roots the OS trusts for TLS plus LocalRouter's CA, refreshed every 60 s to
  follow OS trust changes. Fixes commands run by a proxied Codex (`gh`, `curl`, …) failing TLS
  for every non-intercepted host. Existing Codex configs migrate automatically. See
  `plan/2026-11-25-PROXY_CA_BUNDLE_OS_TRUST_MIRROR.md`.

Behaviour change users may notice: Aider's bundle follows the OS trust store instead of certifi.
