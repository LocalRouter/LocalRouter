## Scope since v0.0.193

- Tray icon color mode (Settings → Appearance → Colors). Monochrome (default) is unchanged.
  Color fills usage gauges in their vendor's color (Anthropic orange, OpenAI blue), stacks the
  All request graph by vendor (Anthropic bottom, OpenAI above, the rest on top), colors provider
  and model panes, and draws frames toned down. On macOS the color icon is non-template and
  follows the status item's appearance. See `plan/2026-11-25-TRAY_COLOR_MODE.md`.
- Test fix: `lr-skills` zip update test gives the rewritten archive a distinct mtime (same-length
  rewrites within one Linux timestamp tick reused the cached archive hash).
