## Scope since v0.0.194

- Tray color mode stacks traffic recorded by the HTTPS proxy (Claude Code, Codex: provider names
  `anthropic` / `openai`), which v0.0.194 left as a plain graph.
- Every provider has a color (`tray_stats.provider_colors`, built-in defaults: Anthropic orange,
  OpenAI blue, a fixed palette for the rest); the All graph stacks one layer per provider.
- Every tray item can carry its own color (`items[].color`), clients included.
- Settings: a swatch per item row and a picker per provider. See
  `plan/2026-11-25-TRAY_COLOR_MODE.md`.
