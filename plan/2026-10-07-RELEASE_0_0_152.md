## Incident: stalled Ubuntu mirror
Attempts 1–3 of run 37664467849 never got past "Install Linux dependencies"
on the x86_64 Linux build (ubuntu-22.04): `apt-get update` stalled on
`azure.archive.ubuntu.com` until the 60-minute job timeout (attempt 1), or
was cancelled after 15 and 10 minutes (attempts 2 and 3). The other four
platforms built on attempt 1; no GitHub release was created.

Attempt 4 (`gh run rerun --failed`, about an hour later) got past the
apt step and published the release, but "Snap - amd64" hit its 45-minute
timeout: snapcraft's stage-package downloads were still taking 10–30 s each.
Attempt 5 re-ran only that job and attached the snap.

The release has all 32 assets (same set as v0.0.151), and every
`latest.json` URL resolves. Snap Store and package-manager publishing are
skipped by the workflow, as in v0.0.151.

53093764 adds `scripts/ci-apt-config.sh`, run before every apt step in the
CI and Release workflows: it drops the Azure mirror from the runner's mirror
list and bounds apt fetches with timeouts and retries, and each apt step has
a 15-minute timeout. Reruns of the 0.0.152 run used the workflow from its
original commit, so it applies from the next release. snapcraft fetches stage
packages on its own and is not covered by it.
