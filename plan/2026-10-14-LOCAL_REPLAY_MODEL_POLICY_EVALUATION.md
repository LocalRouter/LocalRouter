User promoted local replay to P1. It follows session affinity/cache accounting and precedes exact response caching. Start with manual comparisons, not traffic splits or an automated prompt platform. The monitor is a bounded in-memory ring; opening a captured request does not authorize retaining it permanently. `_truncated` markers, excerpts and redacted payloads are not full requests and cannot be reconstructed from previews. Imported requests are explicit user-selected source data, never an excuse to mine other logs.

The replay editor uses the existing Try It Out/client connection surface. Experiments must use a normal selected client, rather than the privileged internal test token, so model access, current privacy policy, scanning and budgets still apply. MCP execution must be suppressed in the server pipeline even for clients normally configured with automatic MCP tool injection. Provider-bound continuation and live tool actions are excluded from comparison; show a clear editable-input error rather than silently moving signed state.

Classifier-policy evaluation can use the existing explicit preview/classifier path with a saved policy snapshot and current client constraints; model comparison executes the selected allowed models. Record the effective policy and configuration fingerprints for each run, without credentials. Historical snapshots are evidence for reproducibility and cannot bypass current policy or resurrect revoked access.

Local storage is bounded and atomic; datasets and results are sensitive local files, not encrypted merely because they have hashed identifiers. Save/export requires a deliberate user action. Closing or restarting must not restart paid inference. A cancelled/timed-out call can have unknown final spend. A judge model is optional, user-selected and separately invoked/costed; deterministic checks do not invoke inference.

## Implementation review

The Replay / Compare tab is available from Try It Out in normal client mode. The monitor opens a complete captured request as a sanitized editable draft; unsupported, truncated, redacted and provider-bound captures produce an explicit error. Opening, importing, loading and cached-only cost preview never dispatch inference. Users select model targets or copy/edit the current classifier policy snapshot. Every model/classifier/judge call uses the selected enabled gateway client's current secret and ordinary loopback HTTP ingress, including permission, scanning, quota and guardrail checks. Redirects and environment proxies are disabled on that local connection. No privileged internal test token, trace-hop bypass or automatic retry is used.

The shared classifier rubric and answer parser are reused. Model and classifier runs remain distinct; native classifier overhead is recorded separately. Optional judging starts a separate child experiment only after explicit selection of finished results and a model/rubric. Scores are labelled model assessments, with a rubric fingerprint. Cases support text, regex, JSON validity/pointer and expected-route checks without inference.

Inputs and results remain in bounded memory until Save. Datasets and historical results can be imported/exported; imported runs receive fresh ids, are labelled unverified historical snapshots and never resume work. Local JSON artifacts use atomic private files, UUID-only paths, revision checks, symlink rejection and explicit deletion. Limits: 64 cases, 16 targets, 1 MiB per input, 8 MiB selected cases/checks, 2 MiB target policies, two active/eight retained experiments, 512 KiB per live response, 24 MiB live result bodies, 32 MiB per saved artifact, 128 artifacts/256 MiB storage. Saved running snapshots report interruption and unknown later outcomes after reopening. Deleting an artifact cannot silently resurrect an old revision; saved runs are separate retained artifacts.

Tool definitions and callable controls are removed at ingress. MCP injection, MCP prefetch and the deferred-MCP firewall shortcut are disabled for replay across Chat, Completions and Responses. Tool history remains data and returned calls are never executed. Replay uses fresh private session ids, strips transport credentials/control state and retains gateway restrictions. Native decisions omit chat-only stream fields. Reported and estimated spend are separate partial sums; missing prices, unknown cache rates and cancelled/incomplete outcomes are never presented as zero-dollar calls. Cost preview uses cached pricing and rough token/output-cap estimates; it is neither a price guarantee nor a classifier call.

Plan Review, Test Coverage Review and Bug Hunt addressed environment proxy inheritance, credential casing, native stream rejection, realistic strategy ownership in authenticated fixtures, imported-run resumption, missing cache-price evidence, persisted-header mismatches, symlink paths, storage revisions, cancellation and separate judge charges.
