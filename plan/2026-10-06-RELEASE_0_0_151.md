## Incident: partial publish
Release run 37518823250 attempt 1 built all five platforms, but "Create
GitHub Release" failed when GitHub returned HTTP 500 uploading
`LocalRouter_0.0.151_x86_64.rpm`. The release was already published with 12
of 32 assets, and its `latest.json` pointed the Intel macOS, Linux and
Windows updaters at missing files, so auto-update failed on those platforms.

Recovery: `gh run rerun --failed` (attempt 2) re-ran the release step and
its dependents (Snap, Flatpak, post-release) from the same build artifacts
without bumping the version again. Afterwards the release had all 32 assets
(same set as v0.0.150), and every `latest.json` URL resolved to an uploaded
asset. Package-manager publishing is skipped by the workflow, as in
v0.0.149 and v0.0.150.
