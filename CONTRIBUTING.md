# Contributing to LocalRouter

Thank you for your interest in LocalRouter!

## TL;DR

- ✅ **Bug reports** — via [GitHub Issues](https://github.com/LocalRouter/LocalRouter/issues)
- ✅ **Feature requests** — via [GitHub Issues](https://github.com/LocalRouter/LocalRouter/issues)
- ❌ **Pull requests / code contributions** — not accepted

## How this project is developed

LocalRouter is **fully coded by a Coding Agent**. No human-written code and no
external code contributions are allowed in this repository. This keeps the
codebase consistent and allows issues to be turned around quickly.

Because of this, **pull requests are not accepted and will be closed without
review**. Please do not submit code — it cannot be merged regardless of
quality.

## How to contribute

### Report a bug

Open a [GitHub Issue](https://github.com/LocalRouter/LocalRouter/issues/new)
and include:

- What you did, what you expected, and what happened instead
- Your OS and LocalRouter version
- Relevant logs or screenshots, if available

### Request a feature

Open a [GitHub Issue](https://github.com/LocalRouter/LocalRouter/issues/new)
describing:

- The problem you are trying to solve
- How you'd like it to work
- Any alternatives you've considered

Feature requests and bug reports are **handled promptly**, and fixes or new
features ship in a **new release shortly** after being addressed.

### Want to change the code yourself?

LocalRouter is licensed under **AGPL-3.0-or-later** — you are welcome to
**fork the repository** and maintain your own version under the terms of the
license.

## Questions

If you're unsure whether something is a bug or a feature request, just open an
issue anyway — we'll take it from there.
