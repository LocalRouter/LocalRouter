# Repository instructions

Follow `CLAUDE.md` for project conventions and validation requirements.

## Commit and push

- Always commit and push your completed, validated work to the current branch's configured upstream unless the user explicitly instructs otherwise.
- The user has given standing authorization to push; do not ask for confirmation each time.
- Stage only your task's changes. Preserve unrelated user changes.
- Use a normal push, never a force push. If pushing fails, investigate and resolve it without discarding others' work; report any unresolved blocker.
